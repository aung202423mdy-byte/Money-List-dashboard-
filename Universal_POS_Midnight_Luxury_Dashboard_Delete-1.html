Cloud Sync

လက်ရှိဗားရှင်းတွင် ဒေတာများကို ဖုန်းအတွင်းသိမ်းထားပြီး Backup/Restore ပါဝင်သည်။ ဖုန်းနှစ်လုံးကြား အလိုအလျောက် Cloud Sync သုံးရန် Firebase Project နှင့် လုံခြုံသော Login/Database စည်းမျဉ်းများ ချိတ်ဆက်ရပါမည်။ မချိတ်ဆက်ရသေးသည့်အတွက် Cloud Sync လုပ်နေပြီဟု မယူဆပါနှင့်။
